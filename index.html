How to use Insight Phantom

1. The Master Key: Editor Mode

To start customizing your data, you MUST enable Editor Mode. This is a safety feature to prevent accidental edits during presentations.

  1. Go to your Profile Page.
  2. Click the Share Profile button.
  3. Toggle the Editor Mode switch to ON.

2. Customizing Everything

Professional Dashboard
Navigate to the Dashboard and open the Settings (Gear) icon. While Editor Mode is enabled, available numbers and date ranges can be customized.

Reel Insights
Open any Reel and select View Insights. Use the available controls to customize the displayed insights data.

3. Uploading Content

Sharing content is available through the main content creation controls.

  • Bottom Navigation: Tap the center Plus icon.
  • Profile Header: Tap the Plus icon to add a new post or reel.
  • Explore Page: Use the Add Post option when available.

4. Pro Tips & Hidden Controls

Long Press & Three Dots
Check available item menus and three-dot controls for additional options.

Real Video Previews
Uploaded videos can appear in profile and preview areas when supported by the platform.
